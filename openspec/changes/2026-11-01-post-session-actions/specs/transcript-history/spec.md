# Spec Delta

## ADDED Requirements

### Requirement: Export a just-ended session from the live screen
The system SHALL let the user export the transcript of a just-ended live
session from the live screen's post-session card, via the same plain-text or
Markdown share-sheet flow as the history detail view.

#### Scenario: Share from the post-session card
- **WHEN** the user taps Share on the post-session card of a just-saved session
- **THEN** the plain-text/Markdown chooser is shown and the chosen export is offered to the share sheet
